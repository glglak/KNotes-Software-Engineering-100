# Contributing

Contributions are welcome, especially when they improve the usefulness rather than merely expand the list.

## Good contributions

- Challenge a ranking with a clear engineering argument.
- Suggest a missing book and explain what durable idea it adds.
- Improve a one-sentence takeaway without turning it into a generic summary.
- Flag advice that has materially aged and propose a 2026-aware framing.
- Add or improve a role-based reading path.

## Principle

The sentence should answer: **“If I remember only one idea from this book, what should it be?”**

Please do not paste copyrighted passages from books. Summaries should be original paraphrases.
